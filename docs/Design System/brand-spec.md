# Brand Spec — Keairan Citanduy

## Identitas
- **Merek:** KEAIRAN CITANDUY
- **Tagline:** Platform Intelijen Hidrologi Terpadu · Wilayah Sungai Citanduy
- **Sub-line:** Solusi hibrida: mitigasi risiko korporat dan layanan ketahanan masyarakat.

## Sumber gaya
Gaya editorial dokumenter ala National Geographic — judul Bodoni-moderna yang
berani, fotografi naturalistik, hierarki tipografi tegas, latar dominan netral,
dan satu warna aksen yang muncul terbatas. Konten dan domain sepenuhnya
diambil dari cetak biru "Platform Intelijen Hidrologi Terpadu WS Citanduy"
(BBWS / SIH3, 4 September 2026).

## Token warna (OKLch)
- `--bg`        : `oklch(98% 0.005 95)`        — Kertas hangat
- `--surface`   : `oklch(94% 0.012 90)`        — Panel editorial
- `--fg`        : `oklch(16% 0.01 250)`        — Tinta pekat
- `--muted`     : `oklch(45% 0.015 250)`       — Teks sekunder
- `--border`    : `oklch(86% 0.01 90)`         — Garis editorial
- `--accent`    : `oklch(82% 0.18 95)`         — Kuning NatGeo (CTA, sorotan)

## Aksen domain
- `--water`     : `oklch(45% 0.09 220)`        — Biru sungai dalam
- `--paper-dark`: `oklch(18% 0.01 250)`        — Latar gelap feature
- Status banjir:
  - Normal    `oklch(60% 0.16 145)`           — Hijau stabil
  - Waspada   `oklch(78% 0.16 80)`            — Kuning waspada
  - Siaga     `oklch(55% 0.22 25)`            — Merah siaga

## Tipografi
- Display : `"Bodoni Moda", "Playfair Display", "Times New Roman", serif`
- Body    : `"Inter", "Helvetica Neue", Arial, sans-serif`
- Mono    : `"JetBrains Mono", "IBM Plex Mono", ui-monospace, monospace`

## Aturan visual
1. Latar kertas hangat dengan satu blok pekat gelap sebagai pemutus irama.
2. Judul serif besar, line-height rapat, berat 700/800 — maksimal 3 baris.
3. Foto naturalistik mendominasi; gunakan overlay sudut dengan latar solid.
4. Kuning aksen hanya untuk CTA, label kecil, dan tanda kutipan.
5. Data angka pakai mono dan diberi label huruf besar 11px untuk konsistensi.
6. Konten berbahasa Indonesia; angka pakai format Indonesia (titik ribuan).
